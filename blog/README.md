# Blog

사람이 읽고 "공개해도 된다"고 결정한 글만 들어가는 자리다. 무엇이 여기 들어올지는
도구가 아니라 사람이 정한다 — 직접 쓰거나 다듬은 뒤 공개를 결정한 글만 커밋한다.
이 저장소가 public 이므로 여기 있는 파일은 전부 인터넷에 공개된 것으로 취급한다.

**자동 생성 초안은 여기 들어오지 않는다.** 초안의 착지점은 저장소 바깥
`~/.warruru/drafts/YYYY/MM/` 으로 정해져 있고, 그 쓰기 어댑터는 구현 계획 Task 8 에서
들어온다. 저장소가 public 이라 그렇게 정했다 — 미완성 사고 과정이 담긴 초안이
`git add -A` 한 번에 인터넷으로 올라가는 사고를 `.gitignore` 한 줄로는 막지 못한다.

## 지금 있는 글

```text
blog/
├── CS/          CS·자료구조·네트워크·운영체제 학습 글 (1편)
├── warurulab/   이 프로젝트의 설계 결정과 개발 과정 (4편)
│   ├── devtalk/
│   ├── devlog/
│   └── mcp/
└── README.md
```

## 작성 원칙

- 대화 로그를 그대로 붙이지 않는다.
- 내가 무엇을 몰랐고, 어떻게 이해가 바뀌었는지 남긴다.
- 코드나 설정은 왜 필요한지 함께 설명한다.
- 확인하지 않은 것은 "확인 못 했다"고 적는다. 지어내지 않는다.
