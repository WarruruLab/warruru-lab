## 1. 배경 및 문제 정의

### 1.1 현재 문제

기존 WarruruLab은 5개의 독립 서비스(DevTalk, MCP, DevLog, Ollama, RAG)로 분산 구성되어 있었습니다.

**문제점:**
- 서버 운영 비용이 월 13만원으로 개인 프로젝트에 과도함
- 네트워크 왕복으로 인한 응답 지연 (500ms)
- 서비스 간 통신 복잡도 증가
- 배포 및 관리 부담
- 개인 학습 데이터가 외부 서버에 저장되는 프라이버시 위험

### 1.2 해결 방향

**Local-First All-In-One Agent**

모든 기능을 하나의 통합 에이전트로 통합하고, 로컬에서 실행하여:
- 비용 96% 절감 (월 13만원 → 5천원)
- 응답 속도 10배 향상 (500ms → 50ms)
- 완전한 프라이버시 (로컬 전용)
- 관리 복잡도 80% 감소

## 2. 사용자 페르소나

### 주 사용자: 개인 학습자 (본인)

**특징:**
- 백엔드 개발 학습 중 (Spring Boot, Java, JPA, MySQL)
- Local LLM 활용 희망 (비용 절감 + 프라이버시)
- 학습 기록을 체계적으로 관리하고 블로그로 전환 희망
- Windows와 Mac을 번갈아 사용

**니즈:**
- 빠른 학습 대화 (2-5초 응답)
- 자동 지식 구조화 (수동 정리 부담 제거)
- 블로그 초안 자동 생성
- 개발 작업 기록 (AI Agent 사용 흔적)
- 여러 기기 간 작업 동기화

**제약:**
- 서버 운영 비용 최소화
- 개인 GPU 활용 (RTX 3060 Ti)
- 인터넷 없이도 동작 (선택적 온라인)

## 3. 핵심 목표

### 3.1 비즈니스 목표

1. **학습 효율 극대화**
   - AI 답변으로 빠른 문제 해결
   - 자동 구조화로 복습 용이
   - 블로그 작성 시간 50% 단축

2. **지식 자산 축적**
   - 모든 학습 대화를 knowledge block으로 변환
   - RAG로 과거 학습 기록 재활용
   - 블로그 글을 통한 장기 기억

3. **비용 최소화**
   - 외부 API 사용 0원
   - 로컬 GPU 무제한 사용
   - 월 운영비 5천원 이하

### 3.2 기술 목표

1. **통합 아키텍처**
   - 4개 모듈을 단일 프로세스로 실행
   - 모듈 간 직접 호출 (네트워크 제거)
   - 공통 DB 공유

2. **성능**
   - Chat 응답 시간: 2-5초
   - Structure 처리 시간: 1-3초
   - Draft 생성 시간: 10-30초
   - 실시간 스트리밍 (WebSocket)

3. **확장성**
   - 모듈 독립성 유지 (교체 가능)
   - 플러그인 아키텍처
   - 수평 확장 가능 (필요시 분리)

### 4.1 성능

| 항목 | 요구사항 |
|------|---------|
| **Chat 응답** | 2-5초 (RAG 포함) |
| **Structure 처리** | 1-3초 |
| **Draft 생성** | 10-30초 (고품질 LLM) |
| **동시 사용자** | 1명 (본인만) |

- 모든 데이터는 로컬 저장 (외부 전송 없음)
- API 키 관리 (Tistory OAuth)
- SQL Injection 방지
- XSS 방지 (웹 UI)

### 4.3 안정성

- LLM 타임아웃 처리 (30초)
- DB 트랜잭션 관리
- 에러 로깅 및 복구
- 오프라인 spool (Record Module)

### 4.4 사용성

- 웹 UI 하나로 모든 기능 접근
- 실시간 피드백 (스트리밍)
- 직관적인 UI/UX
- 키보드 단축키 지원

### 4.5 유지보수성

- 모듈별 독립성 (교체 가능)
- 명확한 인터페이스
- 테스트 코드 필수
- 문서 자동 업데이트

## 5. 제약사항

### 5.1 하드웨어

- **로컬 GPU 필수:** RTX 3060 Ti 이상 (12GB VRAM 권장)
- **RAM:** 16GB 이상
- **디스크:** 100GB 이상 (모델 + 데이터)

### 5.2 소프트웨어

- **OS:** Windows 10/11, macOS 12 이상
- **Python:** 3.11 이상
- **Docker:** 24.0 이상
- **Ollama:** 0.1.0 이상

### 5.3 네트워크

- **기본:** 오프라인 동작 (로컬 전용)
- **선택:** Tistory 발행, 동기화 시 인터넷 필요

### 5.4 데이터

- **학습 기록:** 무제한
- **블로그 초안:** 무제한
- **개발 기록:** 1년 (자동 정리)
- **RAG 벡터:** 100만 개 (Qdrant 로컬)
