# packages/agent/docs - 문서 가이드

이 디렉토리는 **통합 AI 에이전트**의 명세서를 담고 있습니다.

---

## 📚 문서 목록

### 1. requirements.md (요구사항 명세서)

**목적:** 왜 이 서비스가 필요한지, 무엇을 달성해야 하는지 정의

**포함 내용:**
- 배경 및 문제 정의
- 사용자 페르소나
- 핵심 목표 (비즈니스, 기술)
- 비기능 요구사항 (성능, 보안, 확장성)
- 제약사항
- 성공 지표

**작성 시점:** 프로젝트 시작 전
**업데이트:** 목표 변경 시

---

### 2. features.md (기능 명세서)

**목적:** 서비스가 제공하는 모든 기능을 상세히 기술

**포함 내용:**
- 기능 목록 (우선순위 포함)
- 각 기능의 입력/출력
- 사용 시나리오
- 예외 상황 처리
- 의존성
- 제한사항

**작성 시점:** 요구사항 확정 후
**업데이트:** 기능 추가/변경 시

---

### 3. interface.md (인터페이스 명세서)

**목적:** 외부와의 통신 방법을 정의 (API, 프로토콜)

**포함 내용:**
- REST API 엔드포인트
- WebSocket 프로토콜
- MCP 프로토콜
- 요청/응답 스키마
- 에러 코드
- 인증/권한
- Rate Limiting

**작성 시점:** 기능 명세 확정 후
**업데이트:** API 변경 시 (버전 관리 필수)

---

## 🤖 AI Agent 작업 가이드

### 문서 작성 순서

```
1. requirements.md 작성
   ↓ (요구사항 확정)
2. features.md 작성
   ↓ (기능 확정)
3. interface.md 작성
   ↓ (API 확정)
4. 상세 설계 (내부 아키텍처)
   ↓
5. 구현 시작
```

### 문서 작성 규칙

**Markdown 형식:**
- 명확한 제목 계층 (`#`, `##`, `###`)
- 코드 블록에 언어 지정 (```python, ```http)
- 표 사용 권장 (비교, 파라미터 등)

**예시 포함:**
- API 호출 예시 (curl, httpie)
- 요청/응답 예시 (JSON)
- 사용 시나리오 (구체적 상황)

**버전 관리:**
- 문서 상단에 **작성일** 및 **최종 업데이트** 명시
- API 변경 시 **CHANGELOG** 섹션 추가
- Breaking Change는 **명확히 표시**

**다이어그램:**
- Mermaid 다이어그램 사용 권장
- ASCII art도 가능
- 복잡한 흐름은 시각화 필수
