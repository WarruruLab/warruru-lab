🦀 WarruruLab 개요 파이프라인 데이터 서비스 지도 용어

학습 대화가 블로그 글이 되기까지

데이터가 어느 서비스를 거쳐 무엇으로 바뀌는지 단계별로 따라가는 문서입니다.

개인 학습용 Local-First AI 에이전트입니다. 질문을 하면 과거에 배운 내용을 먼저 검색해 답하고, 그 대화를 재사용 가능한 조각으로 잘라 쌓아두었다가, 모아서 블로그 초안까지 만듭니다. 모델은 내 컴퓨터 GPU에서 돌기 때문에 학습 기록이 외부로 나가지 않습니다.

아직 대부분이 명세 단계입니다. 아래 지도에서 왼쪽에 초록 줄이 그어진 카드만 실제로 돌아가는 서비스이고, 나머지는 문서로만 존재합니다.

      서비스 지도

      서비스를 클릭하면 역할 · 기술 · 설계 근거가 옆에 나옵니다. 카드에 마우스를 올리면 그 서비스에 연결된 화살표만 켜집니다.

      흐름
      8개 용어

      용어

      지도에서는 아는 말로 바꿔 적었습니다. 코드와 문서에 실제로 쓰인 이름은 괄호 안에 있습니다.

      기록 저장 서버 (데몬 / daemon)
      창 없이 백그라운드에 계속 떠 있는 프로그램. 사용자가 켜고 끄지 않고, 요청이 오면 받아서 처리합니다. 브라우저로 127.0.0.1:8787 에 접속하면 이 프로그램이 만든 화면이 나옵니다.
      기록 전달기 (어댑터 / adapter)
      말이 서로 통하지 않는 두 쪽 사이에서 형식을 바꿔 옮겨주는 중계 프로그램. 여기서는 AI 에이전트가 쓰는 방식을 저장 서버가 알아듣는 HTTP 요청으로 바꿔줍니다.
      임시 보관함 (스풀 / spool)
      받는 쪽이 준비되지 않았을 때 잠시 쌓아두는 대기열. 프린터가 꺼져 있어도 인쇄 작업이 쌓여 있다가 켜면 인쇄되는 것과 같습니다.
      MCP
      AI 에이전트가 외부 도구를 불러 쓰는 표준 규약. 이 프로젝트에서는 에이전트가 start_work 같은 도구를 부르는 통로입니다.
      stdio
      두 프로그램이 네트워크를 거치지 않고 표준 입출력으로 직접 주고받는 통신 방식.
      RAG
      답을 만들기 전에 과거 기록을 먼저 검색해 근거로 붙여주는 방식. 모델이 모르는 내 학습 이력을 답변에 반영시키는 장치입니다.
      임베딩 · 벡터 DB
      문장을 숫자 배열로 바꿔 저장해두면, 글자가 달라도 뜻이 비슷한 것을 찾아낼 수 있습니다. 그 숫자 배열을 담아두고 검색해주는 저장소가 벡터 DB(Qdrant)입니다.
      엔드포인트
      POST /v1/works 처럼 “이 주소로 이렇게 요청하면 이걸 해준다” 는 약속 하나하나.
      구현 완료 명세 확정 · 미구현 계획 기성 컴포넌트 (설정 대상) · 실선 = 확정된 데이터 경로, 점선 = 폴백 또는 미해결 중복
