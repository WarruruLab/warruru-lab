🔄 통합 에이전트 작업 흐름
1️⃣ 사용자 학습 대화
브라우저 → http://localhost:8787 → Chat Module
→ RAG 검색 (Qdrant) → Ollama LLM → 응답 생성 → DB 저장
⬇️
2️⃣ 자동 지식 구조화
Chat Module → Structure Module (MCP 로직)
→ Ollama (route + metadata) → Knowledge Block 생성
⬇️
3️⃣ RAG 인덱싱
Knowledge Block → Embedding (nomic-embed-text)
→ Qdrant upsert → 검색 가능한 지식 베이스 확장
⬇️
4️⃣ 블로그 초안 생성
사용자 Topic 선택 → Draft Module
→ Block 조회 + RAG Context → Ollama (고품질 LLM) → 초안 생성
⬇️
5️⃣ 검토 & 공개
사용자 검토 & 수정 → Markdown 저장 (로컬)
→ Git push → Portfolio Site (GitHub Pages) → 공개

⚖️ 기존 vs 새로운 아키텍처 비교

❌ 기존 아키텍처 (분산)

  • 5개 독립 서비스 (DevTalk, MCP, DevLog, Ollama, RAG)
  • 서버 운영 비용 월 13만원
  • 네트워크 왕복으로 지연 발생
  • 서비스 간 통신 복잡
  • 배포 & 관리 부담
  • GPU 서버 비용 높음
  • 프라이버시 위험 (서버 저장)

✅ 새 아키텍처 (통합)

  • 1개 통합 에이전트 + 보조 서비스
  • 운영 비용 월 5천원 (전기세만)
  • localhost 통신으로 지연 거의 0
  • 모듈 간 직접 호출
  • Docker Compose 하나로 관리
  • 로컬 GPU 무료 활용
  • 완전한 프라이버시 (로컬 전용)

💬 Chat Module

📋 핵심 기능

  • CS/프레임워크 학습 대화
  • RAG 기반 답변 품질 향상
  • 세션별 context 유지
  • 실시간 응답 (WebSocket)

🔄 작업 흐름

사용자 질문 입력 ↓ RAG 검색 (Qdrant - 유사 학습 기록) ↓ Context 구성 (최근 대화 + RAG 결과) ↓ Ollama LLM 호출 (qwen2.5:3b) ↓ 응답 생성 & 저장 ↓ 자동으로 Structure Module 트리거

⚡ 성능 최적화

  • localhost 통신으로 네트워크 지연 0ms
  • RAG 캐싱으로 반복 검색 속도 향상
  • WebSocket으로 실시간 스트리밍
  • 경량 LLM으로 빠른 응답 (2-5초)
🧠 Structure Module

📋 핵심 기능

  • 대화를 knowledge block으로 자동 구조화
  • 2단계 LLM: route (qwen) + metadata (gpt)
  • block type 자동 분류 (concept, comparison, example 등)
  • RAG 인덱싱 준비

🔄 작업 흐름

Chat Module에서 메시지 수신 ↓ 1단계: Route 판단 (Ollama qwen2.5:3b) ├─ APPEND (기존 블록에 추가) └─ NEW_BLOCK (새 블록 생성) ↓ 2단계: Metadata 생성 (Ollama gpt-oss-20b) ├─ blockType ├─ status ├─ topic ├─ summary └─ tags ↓ Knowledge Block 저장 (DB) ↓ RAG Engine으로 전달 (embedding)

🏷 Block Types

  • concept: 개념 설명
  • comparison: 비교 분석 (A vs B)
  • example: 구체적 예시/코드
  • misunderstanding: 오해했던 내용
  • summary: 정리/요약
  • blog_candidate: 블로그 글감
📝 Draft Module

📋 핵심 기능

  • Knowledge block을 블로그 초안으로 전환
  • 고품질 LLM 사용 (gpt-oss-20b)
  • RAG context로 근거 강화
  • Topic 기반 글감 그룹핑

🔄 작업 흐름

사용자가 Topic/Block 선택 ↓ Structure Module에서 Block 조회 ↓ RAG 검색 (관련 학습 기록 + CS 지식) ↓ Prompt 구성 (Block + RAG Context) ↓ Ollama LLM 호출 (gpt-oss-20b - 고품질) ↓ 초안 생성 (Markdown) ↓ 사용자 검토 & 수정 ↓ 최종 승인 시 Blog 저장

✍️ 초안 품질

  • 기술적 정확성 (RAG로 검증)
  • 구체적 예시 포함
  • 학습 과정 스토리텔링
  • 코드 예제 실행 가능
  • SEO 최적화 구조
📊 Record Module

📋 핵심 기능

  • AI Agent 개발 작업 기록
  • MCP 프로토콜로 stdio 통신
  • 오프라인 spool 메커니즘
  • 날짜별 작업 조회

🔄 작업 흐름

AI Agent (Codex/Claude Code) ↓ stdio (MCP) warruru-mcp (어댑터) ↓ HTTP Record Module (Daemon) ↓ SQLite 저장 (~/.warruru/warruru.db) ↓ Web UI 조회 (http://localhost:8787/record)

💾 기록 데이터

  • Work Session (작업 시작/종료)
  • Checkpoint (중요 결정 지점)
  • Git Context (브랜치, 커밋)
  • Tool Info (사용한 AI 도구)
