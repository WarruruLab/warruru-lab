# services/sync - 크로스 플랫폼 동기화

## 서비스 개요

**Sync Service**는 Windows ↔ Mac 간 작업물 동기화 서비스입니다.

### 핵심 기능

- 자동 백업 (암호화)
- 작업물 병합 (같은 날짜 기준)
- 충돌 해결 (타임스탬프 + 유사도)
