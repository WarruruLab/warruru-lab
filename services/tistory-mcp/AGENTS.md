# services/tistory-mcp - Tistory 블로그 연동

## 서비스 개요

**Tistory MCP**는 완성된 블로그 초안을 Tistory에 자동 발행하는 MCP 서비스입니다.

### 핵심 기능

- OAuth 인증
- 초안 → Tistory 발행
- 카테고리/태그 설정
- 공개 범위 제어
