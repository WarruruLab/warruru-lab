# services/ollama - Local LLM 서버

## 서비스 개요

**Ollama**는 로컬 GPU에서 LLM을 실행하는 서버입니다.

### 모델

- **qwen2.5:3b** - 빠른 응답 (Chat, Structure route)
- **gpt-oss-20b** - 고품질 글 생성 (Structure metadata, Draft)
- **nomic-embed-text** - Embedding (RAG)
